# Hash API для Digital Parallels

Локальный API-сервис для фиксации загруженных материалов через SHA256 и первичного извлечения аннотации.

## Запуск

Из папки проекта:

```bash
python3 work/hash_service_api/app.py
```

По умолчанию сервис запускается на:

```text
http://127.0.0.1:8091
```

## API

- `GET /health` — проверка, что сервис работает.
- `POST /api/v1/documents/register` — регистрация файла по локальному пути.
- `GET /api/v1/records?limit=20` — последние фиксации.
- `GET /api/v1/records/by-hash?sha256=<hash>` — поиск записи по хэшу.
- `POST /api/v1/discussion-registrations` — сохранение первого этапа регистрации для дискуссий.
- `GET /api/v1/discussion-registrations?limit=50` — последние регистрации первого этапа.

## Как это связано с ботом

`work/tgbot/bot.py` после загрузки материала и выбора главы отправляет файл в этот API.
Ответ API сохраняется в `work/tgbot/data/submissions.json` в поле `hash_registration`.

Если API не запущен, бот все равно сохранит материал, но напишет, что фиксация хэша временно недоступна.

Если формат поддерживается, API также пытается найти первый содержательный фрагмент для аннотации.
Сейчас поддерживаются: `.docx`, `.pptx`, `.odt`, `.odp`, `.rtf`, `.txt`, `.md`, `.csv`.
Для этого не нужны внешние Python-библиотеки.

`work/discussion_bot/bot.py` после ввода ФИО отправляет первый этап регистрации в этот же API.
Если API не запущен, вход в группу все равно продолжит работать по локальному JSON бота.

## Как это связано с сайтом

`work/web_w/script.js` обращается к `http://127.0.0.1:8091`, показывает статус сервиса и последние фиксации.
