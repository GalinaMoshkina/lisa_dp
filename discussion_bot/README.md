# Бот первого этапа регистрации DP-Club

Бот `@dp_discussion_reg_bot` собирает ФИО пользователя и автоматически принимает заявку на вступление в дискуссионную группу, если пользователь уже прошел регистрацию.

## Что должен уметь бот

1. Пользователь пишет боту `/start`.
2. Бот просит указать ФИО полностью.
3. Пользователь отправляет фамилию, имя и отчество.
4. Бот сохраняет регистрацию в `data/registrations.json`.
5. Бот отправляет регистрацию в общий локальный API, если он запущен.
6. Бот показывает одну кнопку перехода в группу: `https://t.me/+DRbehXtIw0AwOTNi`.
7. Пользователь отправляет заявку, а бот автоматически одобряет ее, если Telegram ID пользователя найден в регистрации.

## Важная настройка Telegram

Для автоматического принятия заявок бот должен быть добавлен администратором в дискуссионную группу:

`https://t.me/+DRbehXtIw0AwOTNi`

Права бота:

- приглашать пользователей;
- принимать заявки на вступление / управлять участниками.

Если бот не администратор, Telegram не даст ему выполнять `approve`.

## Запуск

```bash
cd /home/gala/.vscode/2course/work/discussion_bot
pip install -r requirements.txt
python bot.py
```

Токен хранится в `.env`.

## Связь с API

Перед запуском можно поднять общий локальный API:

```bash
python3 ../hash_service_api/app.py
```

После ввода ФИО бот отправит регистрацию на:

```text
http://127.0.0.1:8091/api/v1/discussion-registrations
```

Если нужно изменить адрес API, добавьте в `.env`:

```bash
CORE_API_URL=http://127.0.0.1:8091
```

Если API не запущен, бот продолжит работать через свои локальные JSON-файлы.

## Данные

- `data/registrations.json` — зарегистрированные пользователи.
- `data/join_requests.json` — история заявок на вступление.
- `data/logs.json` — журнал действий.

## Команды

- `/start` — начать регистрацию.
- `/profile` — посмотреть сохраненное ФИО.
