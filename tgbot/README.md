# Telegram-бот регистрации Digital Parallels

Бот регистрирует пользователя по ФИО и телефону, затем принимает редактируемый файл материала и предлагает выбрать ветку публикации.

## Запуск

1. Создайте бота через `@BotFather` и получите токен. Username вида `@dp_registration_bot` нужен пользователям, а для запуска кода нужен именно токен.
2. Установите зависимости:

```bash
pip install -r requirements.txt
```

3. Создайте файл `.env` рядом с `bot.py`:

```bash
cp .env.example .env
```

Откройте `.env` и вставьте токен от BotFather:

```bash
BOT_TOKEN=1234567890:ваш_секретный_токен
```

4. Запустите бота:

```bash
python bot.py
```

## Сценарий

1. Пользователь отправляет `/start`.
2. Бот просит ФИО.
3. Бот просит номер телефона.
4. После регистрации появляется кнопка `Опубликовать материал`.
5. Пользователь отправляет редактируемый файл: Word, PowerPoint, Excel, OpenDocument, CSV, RTF, TXT или Markdown.
6. Бот предлагает выбрать главу/ветку.
7. Заявка сохраняется в `data/submissions.json`, файл сохраняется в `uploads/`.

## Команды

- `/start` — начать регистрацию.
- `/profile` — посмотреть сохраненные регистрационные данные.
- `/my_submissions` — посмотреть свои отправленные материалы.
- `/cancel` — отменить текущий сценарий.

После регистрации бот также показывает постоянное меню с кнопками:

- `Опубликовать материал`
- `Мой профиль`
- `Мои материалы`
- `Помощь`
- `Отмена`

## Хранение данных

- `data/users.json` — зарегистрированные пользователи.
- `data/submissions.json` — заявки на публикацию.
- `data/logs.json` — журнал действий пользователей.
- `uploads/` — загруженные редактируемые файлы материалов.

## Фиксация хэша материала

Перед запуском бота можно запустить локальный Hash API:

```bash
python3 ../hash_service_api/app.py
```

После выбора главы бот отправит загруженный файл в API, получит SHA256-хэш и сохранит его в `data/submissions.json`.

Адрес API по умолчанию:

```text
http://127.0.0.1:8091
```

Если нужно изменить адрес, добавьте в `.env`:

```bash
HASH_API_URL=http://127.0.0.1:8091
```

Позже эти JSON-файлы можно заменить на PostgreSQL и связать бота с сайтом.
